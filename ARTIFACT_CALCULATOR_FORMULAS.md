# ИТОГОВЫЕ ФОРМУЛЫ ДЛЯ КАЛЬКУЛЯТОРА АРТЕФАКТОВ

## 1. Общие принципы

**Качество (Q)** — целое число от 85 до 190+.

**Уровень заточки (L)** — целое число от 0 до 15.

Каждое свойство артефакта имеет:

- `value_at_85` — значение при 85% качестве (из базы)
- `value_at_100` — значение при 100% качестве (из базы)
- `is_harmful` — TRUE, если свойство вредное (красное, увеличивает урон или штраф), FALSE — если полезное (зелёное, сопротивление или бонус).

Все расчёты округляются до двух знаков после запятой (как в игре). В некоторых случаях игра показывает один знак, но округление до двух даёт совпадение.

## 2. Формула для положительных свойств (is_harmful = FALSE)

**Шаг 1: Значение при уровне заточки 0 (L=0)**
```
value_Q0 = value_at_100 × (Q / 100)
```

**Шаг 2: Учёт заточки**
Заточка увеличивает положительные свойства:

```
value_final = value_Q0 × (1 + 0.02 × L)
```

где 0.02 — коэффициент прироста за уровень (2% от базового значения).

## 3. Формула для отрицательных свойств (is_harmful = TRUE)

**Шаг 1: Значение при уровне заточки 0 (L=0)**

Если Q ≤ 100:
```
value_Q0 = value_at_100 × (Q / 100)
```
(линейное масштабирование, как у положительных)

Если Q > 100:
Применяется сброс при переходе на новый ранг (каждые 15% качества, начиная с 101%).

Алгоритм:

```
base = |value_at_100| (модуль)
min = |value_at_85| × (86/85) — значение после сброса (при 101%)
rank = floor((Q - 101) / 15) — номер ранга (0 для 101–115, 1 для 116–130, ...)
start = 101 + rank × 15 — начало ранга
t = (Q - start) / 14 — доля внутри ранга (от 0 до 1)
raw = min + (base - min) × t — значение по модулю
value_Q0 = -raw (знак минус)
```

**Шаг 2: Учёт заточки**
Заточка НЕ влияет на отрицательные свойства:

```
value_final = value_Q0
```

## 4. Полный алгоритм (псевдокод)

```python
def calc_artifact_stat(value_at_85, value_at_100, is_harmful, quality, level):
    """
    Рассчитывает финальное значение свойства артефакта.
    """
    def round2(x):
        return round(x, 2)

    # Шаг 1: значение при уровне 0
    if not is_harmful:  # положительное
        val0 = value_at_100 * (quality / 100)
    else:  # отрицательное
        if quality <= 100:
            val0 = value_at_100 * (quality / 100)
        else:
            base = abs(value_at_100)
            min_val = abs(value_at_85) * (86 / 85)
            rank = (quality - 101) // 15
            start = 101 + rank * 15
            t = (quality - start) / 14
            raw = min_val + (base - min_val) * t
            val0 = -raw

    # Шаг 2: применение заточки
    if is_harmful:
        final = val0
    else:
        final = val0 * (1 + 0.02 * level)

    return round2(final)
```

## 5. Примеры расчёта

**Пример 1: «Атом», качество 125%, заточка +10**

Свойство: Живучесть (положительное, base_100 = 1.0, value_at_85 = 0.85)

```
value_Q0 = 1.0 × 1.25 = 1.25
final = 1.25 × (1 + 0.02×10) = 1.25 × 1.2 = 1.50 → 1.50%
```

Свойство: Радиация (отрицательное, base_100 = -1.28, value_at_85 = -1.09, модули 1.28 и 1.09)

```
min = 1.09 × 86/85 = 1.103
Q=125, rank=(125-101)//15=1, start=116, t=(125-116)/14=9/14≈0.6429
raw = 1.103 + (1.28 - 1.103)×0.6429 = 1.103 + 0.177×0.6429 = 1.103 + 0.1138 = 1.2168 → -1.22
Заточка не влияет → -1.22
```

**Пример 2: «Морозец», качество 124%, заточка +11**

Свойство: Холод (отрицательное, base_100 = 1.0, value_at_85 = 0.85)

```
min = 0.85 × 86/85 = 0.86
Q=124, rank=(124-101)//15=1, start=116, t=(124-116)/14=8/14≈0.5714
raw = 0.86 + (1.0 - 0.86)×0.5714 = 0.86 + 0.08 = 0.94 → -0.94
Заточка не влияет → -0.94
```

## 6. Структура базы данных

В вашем CSV-файле должны быть колонки:

| Колонка | Тип | Описание |
|---------|-----|----------|
| artifact_name | string | Название артефакта |
| stat_name | string | Название свойства (на русском) |
| unit | string | Единица измерения (%, ед, с и т.д.) |
| value_at_85 | float | Значение при 85% качестве |
| value_at_100 | float | Значение при 100% качестве |
| is_harmful | boolean | TRUE если вредное, FALSE если полезное |
| property_type | string | "Основное" или "Дополнительное" |

## 7. Учёт погрешности округления

Все значения в таблице уже округлены до двух знаков, поэтому при расчётах возможна погрешность ±0.01–0.02. Это допустимо, так как в игре округление происходит аналогично. Если требуется абсолютная точность, необходимо хранить значения с большей точностью (3–4 знака), либо использовать реальные значения при 101% (min) из игры.

## 8. Дополнительные свойства

На уровнях заточки +5, +10, +15 у некоторых артефактов появляются дополнительные свойства. Они ведут себя как положительные (линейно растут с качеством и заточкой) и должны быть добавлены в базу данных с соответствующими value_at_85 и value_at_100. Если для них нет данных, их можно игнорировать или вычислить по аналогии.
